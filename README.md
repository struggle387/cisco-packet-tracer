# Packet Tracer Scoop bucket

Install Cisco Packet Tracer **9.0.1 for Windows x64** with [Scoop](https://scoop.sh/).

## Install

Run these commands in PowerShell with Scoop already installed:

```powershell
scoop bucket add packet-tracer https://github.com/struggle387/scoop-packet-tracer
scoop install packet-tracer/packettracer
```

Launch **Cisco Packet Tracer** from the Start menu, or run `packettracer`.

## Packet Tracer documents

Save your labs in a separate folder, such as `Documents\Packet Tracer`. Files saved inside Scoop's installation directory can be removed during updates or uninstall.

Packet Tracer's user folder for settings, saves, and templates can be selected under **Options > Preferences > Administrative**.
